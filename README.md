# Quote Keeper

A simple, elegant web application designed to store, manage, and display favorite quotes. This project focuses on DOM manipulation and local storage persistence without external libraries.

## Features

* **Add Quotes:** interface to input quote text and author names.
* **Persistent Storage:** Uses the browser's `localStorage` API, so quotes remain saved even after refreshing or closing the page.
* **Interactive UI:** Quotes are dynamically rendered as cards.
* **Delete Functionality:** Click on any quote card to permanently remove it from the list.
* **Responsive Design:** Clean, modern CSS with a focus on typography and spacing.

## Tech Stack

* **HTML5:** Semantic structure.
* **CSS3:** Flexbox for layout and custom styling.
* **JavaScript (ES6+):** Logic for DOM manipulation and state management.
